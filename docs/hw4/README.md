## Process around the code

- **Spec and plan in the repo:** [docs/PRD.md](https://github.com/Jasmine-G-uo/tablequeue/blob/52d6428a7c45d5a91df451350e48f86a800f6020/docs/PRD.md) and [docs/plan.md](https://github.com/Jasmine-G-uo/tablequeue/blob/52d6428a7c45d5a91df451350e48f86a800f6020/docs/plan.md), each
  revised after an independent subagent review ([docs/reviews/prd-review.md](https://github.com/Jasmine-G-uo/tablequeue/blob/52d6428a7c45d5a91df451350e48f86a800f6020/docs/reviews/prd-review.md),
  [docs/reviews/plan-review.md](https://github.com/Jasmine-G-uo/tablequeue/blob/52d6428a7c45d5a91df451350e48f86a800f6020/docs/reviews/plan-review.md)).
- **Issues are testable specs:** issues #1–#4 have acceptance criteria. In #2 and #3 the criteria
  are the test descriptions, committed as `it.todo` before any code. In #3 we wrote criteria 1–8;
  criteria 9–12 were drafted by Claude Code during a gap check against the PRD and approved by us.
- **Sprint record:** [docs/process/sprint-1.md](https://github.com/Jasmine-G-uo/tablequeue/blob/52d6428a7c45d5a91df451350e48f86a800f6020/docs/process/sprint-1.md); project board with milestone "Sprint 1".
- **Branch per issue → PR → CI → partner review:** PRs #5 (setup), #6 (auth), #7 (queue), and #8
  (docs) were stacked on the setup branch, each reviewed by the other partner (every comment
  answered with a fix commit or a reason), and merged in order with merge commits, so the
  red/green history is kept: #5 [`8780e98`](https://github.com/Jasmine-G-uo/tablequeue/commit/8780e98544964aff07cec95f4d46c23d7128ba37), #6
  [`865ba78`](https://github.com/Jasmine-G-uo/tablequeue/commit/865ba78cb605f480d5d54d1069a8344b433aac71), #7 [`52d6428`](https://github.com/Jasmine-G-uo/tablequeue/commit/52d6428a7c45d5a91df451350e48f86a800f6020). CI runs six jobs (lint, typecheck, unit tests with
  coverage, integration tests on PostgreSQL, build, `npm audit`), and `main` is protected for
  everyone, admins included.
- **Agent self-validation:** `CLAUDE.md` gives the agent one command to run before every commit
  (`lint`, `format:check`, `typecheck`, `test`), plus integration tests for database changes.
